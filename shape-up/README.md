## The book in one breath

Shape the work first (rough, solved, bounded) → write a 5-ingredient pitch → bet six
uninterrupted weeks with a circuit breaker instead of keeping a backlog → hand the team a
project, not tasks → get one vertical piece done in week one → map scopes, walk them over
the hill → hammer scope against the baseline → ship, let the storm pass, stay debt-free.
